# Straditize Pro Frontend (Web SPA)

现代化的地层图谱交互解译与数字化前端系统，采用 TypeScript + Vite + HTML5 Canvas 2D 架构。专为扫描花粉图谱、沉积剖面与地质多指标图表设计，提供视网膜级高清渲染、亚像素级交互与实时曲线操作。

---

## 🌟 核心特性与架构设计

1. **高性能地学图谱视口引擎 (Viewport Engine)**
   - 滚轮平滑缩放 (`Viewport.zoomAt`)，以鼠标光标为中心自适应缩放（5% ~ 3000%）；
   - 全自由度平移：鼠标右键拖拽、鼠标中键拖拽与空格键+左键拖拽三者等价，符合主流专业制图软件习惯；
   - 自动 DevicePixelRatio (DPR) 视网膜高清自适应渲染，高分辨率屏幕下线条锐利清晰；
   - 支持适应全图（Fit）与 1:1 物理像素快速复位。

2. **属种列边界与刻度标定 (Taxa Column & Scale Anchors)**
   - 属种列基线（`startX`）与满刻度线（`endX`）半透明高亮展示；
   - 鼠标接近边界 6px 阈值自动切换为列宽调整光标（`col-resize`），支持拖拽微调；
   - 两点式物理刻度钉精细标定：基线端点与刻度端点自由对齐，原生支持线性（Linear）与对数（Log）多尺度。

3. **花粉轮廓线与控制锚点交互体系**
   - **添加锚点**：左键点击任意有效位置直接添加控制点，轮廓线平滑吸附；
   - **调整走势**：左键按住已有锚点实时拖拽微调；
   - **删除锚点**：右键点击已有控制点直接删除，曲线自适应重新连接；
   - **撤销 / 重做 (Undo / Redo)**：完整记录加点、拖点、删点与边界调整操作；
   - **即时二值化透视**：按键盘 `B` 键开启双色二值化透视遮罩，直观审查算法提取靶区。

4. **专业分析弹窗与工具集**
   - **属种命名与 OCR 审查 (OcrReviewModal)**：集成 PP-OCRv6 离线识别结果展示，支持多角度旋转与词典自动纠错；
   - **年代-深度模型解译 (AgeDepthModal)**：直接提取图谱中的 Bacon/Bchron 沉积模型中位数曲线与 95% 置信区间；
   - **WPD 级科学导出控制台 (ExportModal)**：执行 $\sum\% \approx 100\%$ 生态学自洽性校验，一键导出无空值 CSV、多表头 Excel、LiPD 格式及 `rioja::strat.plot` 出图脚本。

5. **JSON-RPC 2.0 通信与离线自愈架构**
   - 基于标准 JSON-RPC 2.0 协议与 Python 计算核心 (`straditize_core`) 全双工通信；
   - 提供内置离线演示数据（*Hoya del Castillo* 典型地层剖面），在未连接后端时仍可提供完整的交互体验与离线导出。

## 🚀 启动与构建

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 启动本地开发服务 (支持 HMR 热重载)
npm run dev

# 运行前端核心算法与逻辑回归测试
npm test

# 生产环境打包构建 (严格 TypeScript 类型检查 + 代码分割优化)
npm run build
```

构建产物自动输出至 `frontend/dist/`，由 Python 后端启动时直接提供同源静态托管。
