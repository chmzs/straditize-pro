# S1 夸大列两层墨迹：内线读数 vs 外线÷5（recon-20261117）

> 现场 `.recon_20261117/`（`original.png` 3591×2003、19 列、`data.csv` 203 行）。脚本
> `c:/tmp/recon/s1_evidence.py`（不入库）；逐行明细见 `s1-two-layer-rows.csv`（6080 行）。

## 1. 现象

四列（Picea/Pinus/Betula/Quercus）每行有**两层墨迹**：**内线** = 与轴相连那段墨迹的右缘（未放
大的填充边界，图作者的真实值）；**外线** = 被至少 1 个空白列隔开的独立细线右缘（图上画出来的
放大曲线）。现导出（`data.csv`）取的是**窗口内最右墨迹**，即外线；外线缺失的行退化成内线。同
一列两条口径混用，读数在 1 倍与 4 倍之间跳——不是精度问题，是**口径混用**。

## 2. 方法（判据写死，可判定、可反向）

| 量 | 定义 |
|---|---|
| 墨迹 / 行集合 / 窗口 / 0 点 | `gray < 200`；`y ∈ [316,1836)` 共 1520 行（四列每行都有墨）；`x ∈ [startX,endX)`；`z0 = startX+1` = 940/1000/1063/1126 |
| 轴右缘 | `[startX, startX+9)` 中「列墨迹覆盖率 ≥ 0.95」的最大 x（实测 942/1004/1067/1127） |
| **内线右缘** | 左端 ≤ 轴右缘 的**第一个** run 的右端（run = 单行内连续含墨 x 区间） |
| **外线右缘** | 左端 ≥ 内线右缘 + 2 的**最右** run 的右端 |
| **可分行 sep** | 有外段 且 `内线宽 ≥ 4px` 且 `2.0 ≤ ratio ≤ 7.0` 且 `外线右缘 ≤ endX − 3` |
| 单段行细分 | ±10 行内 sep 行（≥3 行）作参照：`w ≤ p75(内线宽)`→**broken**；`w ≥ p25(外线宽)`→**glue**；否则 **undet** |

`ratio = (外线右缘 − z0)/(内线右缘 − z0)`，px 宽比，同一 0 点。**内线可读行 = sep ∪ broken**。
**旧读法已核实**：按「最右墨迹」重算，与归档控制点 `points[].value = 最右墨迹+1` 在 90.3–96.3%
的行上差 ≤1px（Picea 413/432、Pinus 436/462、Betula 383/424、Quercus 336/349）—— 现导出口径
= 读外线，确证。（列中位不可与 `data.csv` 直接比：`data.csv` 只有 203 个共识行，本文按全 1520
行统计。）**0 点不是任取**：ratio 离散度（IQR/中位）在 `anchor = startX+k`（k=0..7）上扫描，
`k=1` 处最小（0.23；k=0 为 0.24，k=2 为 0.25，k=3/4/5 升到 0.31/0.57/0.38）—— 放大曲线的
放大原点就是 `startX+1`，ratio 才可直接当倍率解释。

## 5. 结论：外线÷5 与内线差多少

1. **现导出比真值高 3.75–4.50 倍**：逐列 现规则/内线 p50 = 4.50/3.75/4.42/3.75；现规则 p50 =
   4.286/5.714/8.095/2.381（%），对应内线 1.190/1.905/1.905/0.952。`data.csv` 无一行读内线。
2. **实测放大倍率 4.17 不是 5**（合并 p50；p5–p95 = 3.00–5.25，93.5% 行落在 [3.0,5.5]）。故
   `外线÷5` 系统性**低 16.6%**；逐行绝对差 p50 = 0.14–0.48 个百分点、p90 = 0.38–0.76，合并
   p50 = 0.286（表 D）。判据：任一 sep 行 ratio 落在 [3.0,5.5] 之外，该行判读不可靠（6.5%）。
3. **偏差随读数变大而非平移**（≈ `0.166 × 内线读数`：1% 处差 0.17，3% 处差 0.5）。要用外线复
   原，正确除数是逐列的 **4.50/3.75/4.42/4.00**，统一用 5 必偏低。
4. **÷5 救不回内线为零的行**：两层都带 +4px 常数底（0 点偏移，见 `recon-20261117.md` §2），
   ÷5 后仍 +0.19% 假非零；内线同口径 +0.95%，把 0 点修到静止位 `startX+5` 后归零（内线 p50
   变 0.238/0.952/0.952/0.000）。真值 0–11px 内两口径高低会翻转，**不存在单一换算系数**。

## 6. 残余不确定性

1. **内线分辨率极低**：内线宽 p50 只有 4–8px，1px = 0.238%；修 0 点后 Picea 46%（352/770）、
   Quercus 89%（198/223）的可读行恰为 0。「读内线」换来量化噪声而非精度——原图内线本就贴轴画。
2. **外线在顶部被窗口截断**：触边行 Picea 61 / Pinus 36 / Betula 189 / Quercus 11，其外线值不
   可用，÷4.17 也复原不了，只能靠内线补（若内线可读）。
3. **Quercus 基本判不开**：sep 仅 12.5%，undet 1048 行（69%）——内线与外线在多数行并成一段，
   不是阈值问题。任何「外线÷k」方案在 Quercus 上无效，只能整列标低置信。
4. **单段行归属判不全**：Picea 459 / Pinus 465 / Quercus 1048 行的单段宽度既不落内线区间也不
   落外线区间，靠 ±10 行局部参照硬分；明确 broken 仅 81 行（四列合计）——**下界**，真实更多。
5. **阈值敏感性已测**：`THR`=128/170/200/215 时 ratio 中位 Picea 4.67/4.58/4.50/4.50、Pinus 3.76/3.78/3.75/3.71、Betula 4.50/4.43/4.42/4.33、Quercus 恒定 4.00 → **倍率结论稳健**；但 Quercus 的 sep 行数 96→190，**计数不稳**，引用时须带阈值。
6. **没做像素级人工标注**：本文只证明几何上确实存在 4.17 倍的两层墨迹，没有独立证明「内线 =
   原始数据」。要闭环需取原论文数值表对照。
