# 夸大列双轨读取器物理模型与工程经验（area_exaggerated）

> **文档定位**：记录花粉图夸大列（Exaggerated Curves）的物理几何特征、历史启发式算法失效根因、真实物理截断判据重构、线宽骨架中心提取算法及全链路架构契约。
> **验证基准**：青藏高原尕海湖真实工程（`Zhou2024QSR_GahaiLake`，3591×2003 像素，19 列花粉属种）。

---

## 一、背景与问题定义

在地层学与花粉分析图件（Pollen Diagrams，如 Tilia/TGView/Rioja 绘制的图件）中，为同时展示常见属种（高丰度）与珍稀属种（极低丰度，如 $0.5\% \sim 2\%$），制图常采用**双轨夸大机制**：
1. **主曲线（内线，1x 实心填充）**：紧贴列零轴（左缘）的黑色实心轮廓，代表真实的 1x 丰度数值。
2. **夸大曲线（外线，Nx 细线或淡色填充，通常 N=5 或 10）**：将丰度值放大 N 倍绘制于外侧，用于肉眼清晰辨识低丰度起伏。
3. **真实截断（True Truncation）**：当花粉丰度极大时，若继续放大 N 倍绘制，曲线将严重飞出当前列右边界并侵入相邻属种列。因此制图规范会在该极端层位**省略/截断外线**，直接以贴轴 1x 黑色实心轮廓示人。

## 二、历史启发式算法的实战失效复盘

在早期设计中，算法采用了基于残差期望与游程位置的启发式判据，在实际工程（如 Gahai Lake 中部段 $y=800 \sim 1100$）遭遇了严重的误判，导致非截断区大量混杂蓝色点（`main_1x`）：

### 1. 致命误判 A：大波峰触界削峰（向左断崖塌陷）
- **现象**：Col 0（$y=841$）、Col 1（$y=840$）、Col 2（$y=960$）等外线 5x 细线画得极其完整饱满，峰形清晰，但由于波峰较大，峰顶恰好延伸触及或贴近列右分割线（$x \approx \text{col\_end} - 1$）。
- **旧逻辑**：单纯根据 `run_end >= border_threshold`，将所有“触碰右边界”的像素一律武断认定为“外线截断”，活生生抹杀画在右侧 $60\,\text{px}$ 的黄色外线峰顶，强行向左暴跌 $50\,\text{px}$ 塌陷到内线 $10\,\text{px}$ 黑块上打蓝点。
- **后果**：视觉上在完整大峰峰顶出现突兀的向左跳崖，生成错误的低丰度数据。

### 2. 致命误判 B：低丰度列全列泛蓝（第四列 Quercus 重灾区）
- **现象**：第四列（Quercus）整体丰度较低（$0.5\% \sim 2\%$），1x 实心轮廓仅 $2 \sim 4\,\text{px}$ 宽，5x 外线仅在 $10 \sim 20\,\text{px}$ 波动，内外线间隙狭窄。
- **旧逻辑**：旧逻辑苛求独立外线必须满足 `run_start > axis_offset + 5`。低丰度时游程间隙过小或偶有粘连，旧算法判定“整列未检出外线”，直接把上千行的控制点全量标记为 `main_1x` 科技蓝（旧诊断图中第四列蓝像素高达 1555 个）。

### 3. 致命误判 C：正常低谷与零值残差过敏
- **现象**：外线从波峰自然回落到贴轴零值或微小起伏低谷。
- **旧逻辑**：因实际跨度远小于局部平均预期，被启发式残差判断为“外线断线”，误打蓝点。

## 三、真实物理模型与判定算法

我们在 `straditize_core/session_parts/digitize.py`（`_read_exaggerated_profile`）中确立了**真实物理截断与双轨连续性模型**：

```
                列宽度 W_col
┌──────────────────────────────────────────────┐
│ [内线实心黑块]            [外线细线或填充]    │
│ 0 ──────► inner_width    run_start ──► run_end
│                                              │
└──────────────────────────────────────────────┘
```

### 1. 真实物理截断（True Truncation）判据
真实截断发生时，丰度极大导致外线飞出，**其贴轴实心黑块自身必定隆起占据了绝大部分列宽**：
$$\text{is\_true\_truncation} = (inner\_width \ge 0.45 \times W_{col}) \land (run\_end \ge border\_threshold)$$
- 只有当内线自身宽度 $\ge 45\% \times W_{col}$ 且整行墨迹贴死列右分割线时，才判定为物理截断，回退抓取内线实心黑块右缘作为 1x 原值，打上科技蓝（`main_1x`）。
- 只要内线黑块自身很细（$< 45\% \times W_{col}$），最右侧墨迹即使触碰右边界，也**100% 确认为外线波峰峰顶**，绝不削峰，输出经典黄（`exagg_Nx`）。

### 2. 考虑线宽的外线骨架中心提取（exagg_style）
为适配不同制图软件产出的夸大图版，系统支持在 Step 6 组级设置 `exagg_style`：
- **`line`（折线/细线夸大，默认）**：
  外线存在物理线宽（1~3px），取游程线宽骨架中心：
  $$x_{outer} = c_{start} + \frac{run\_start + run\_end}{2.0}$$
- **`area`（浅色/淡灰色填充夸大）**：
  外层为半透明或淡灰填充面积，取轮廓最外缘：
  $$x_{outer} = c_{start} + run\_end$$

### 3. 低丰度小起伏与零值保护
- 放宽独立外线检出阈值（`run_start > axis_offset + 3`），确保微小丰度列（如 Quercus）能稳定捕获 5x 外线。
- 只有在预期外线跨度很大（$\ge 30\,\text{px}$）且单行突发断崖式暴跌（落差 $\ge 20\,\text{px}$ 且 $< 0.4 \times$ 预期）时才视作外线漏画断线；正常的波谷起伏 100% 保留为外线点。

## 四、全链路架构契约与设计规范

1. **画布视觉一致性（Visual SSOT）**：
   - 提取的 `points` 与 `control_points` 的物理坐标 $x$ **统一画在图上的外线实际位置**，确保用户在画布检查时，黄色控制点精准咬合在背景 5x 细线上。
   - 点字典携带字段 `"source": "exagg_{N}x"`、`"source": "main_1x"` 或 `"source": "manual"`。
2. **导出与读数统一入口（read_column_values）**：
   - 在 `xscale.py` 的 `read_column_values` 中统一消费 `sources`：
     - 若 `source == "main_1x"`：点位已经是 1x 真实读数，`is_1x=True`，不再除以 $N$；
     - 若 `source == "exagg_Nx"`：点位为外线读数，自动除以 $N$ 换算为 1x 真实丰度。
   - 杜绝在上游提前除以 $N$ 导致画布控制点向左偏离底图细线的违和感。
3. **职责划分与交互极简**：
   - 夸大倍数与样式（`exagg_style`）**仅在 Step 6 组级卡片设置**，列自动继承组属性。
   - Step 7 单列微调侧栏不设冗余干扰项，保证用户操作心智负担最小。

在真实高原湖泊图件（Gahai Lake）中部段（$y=800 \sim 1100$）的对比测试中：
