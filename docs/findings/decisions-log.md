## 使用规则

1. **只追加，不改历史条目。** 需求变化时新开一条并写 `Supersedes: STZ-xx`，旧条目保持原样。
2. 每条必须带**复活条件** —— 一句可判定的触发判据。没有复活条件的关闭等于"以后别问了"，不可接受。
3. 复活流程：满足复活条件时，在 backlog 新开条目并写 `Revives: STZ-xx`，本文件追加一条记录该次复活。
4. 决议必须带**实测数字或代码位置**，不接受"经验上不行"。

## STZ-A10 「等距网格 = 采样层位」概念错位

- 状态：CLOSED ｜ 2026-11-18
- 原提议：把 `samples_from_depth_grid`（按间隔生成）当作采样层位的主通道，把"拐点共识"当次选；并一度表述"等距网格才是真的采样层位"。
- 决议：**错误，推翻。** 两条入口同权，无主次。
- 理由：
  1. 采样层位 = 真实取样并鉴定了花粉等样品的层位。图上表现为填充/折线的折点、标记中心、bar 端点。
  2. **等距取样只是其中一种特例**（钻孔按固定间隔取），非均匀取样（按地层界、按事件层加密）同样常见，不应被当作默认假设。
  3. 拐点共识的价值正在于处理"部分列该层位变化不明显"的情形——目标是最逼近真实采样层，不是为了得到等距。
- 落地：docstring 与 UI 文案改写并入 `STZ-F1`；`samples_from_depth_grid` 定位为"已知取样间隔场景"的专用入口。
- **补充（2026-11-18 追加，不覆盖上文）**：
  1. 目标名以 **`sample_grid`** 为准——它承载的是"一组样品位置"，不是"纵轴上的等分点"；单位由 y 轴当前单位决定（cm / ka / 任意），均匀与非均匀都装得下。**忌用 `y_grid`**（`grid` 暗示等分）。详见 `STZ-F2`。
  2. **年代-深度模型是双向转换器（深度 ↔ 年代），不是"只服务深度输入"的门槛。** 任何单位、任何分布的 `sample_grid` 都应能经它换算。此前把"等年代间隔取样"当成需要新增能力的特例，属于对它的误解。
  3. 该能力**未完全兑现**：`agedepth.py:176` 的 `self.depth_grid` 分支把 sample_grid 当深度直通、不做 `primary_axis` 反演，y 轴声明为年代时会静默错位（不报错、结果看似合理）→ 已开 **`STZ-F3`**（P1）。这是"命名绑死"造成实际行为缺陷的证据，不是命名洁癖。
- 复活条件：若用户图集里等距取样占比 >50%，重新评估是否提为主入口。

## STZ-B4 半宽中心对齐（外部文档 §1.1）

- 状态：CLOSED ｜ 2026-11-18
- 原提议：数据点渲染在几何中心、两侧各扩 ½W；未统一对齐会引入 $\Delta P = \tfrac12 W_{data} - \tfrac12 W_{axis}$，需按中心换算。
- 决议：**不采纳。** 我们的模型覆盖面更宽。
- 理由：
  1. `zero_px = col.startX + axis_stroke`（`ARCHITECTURE.md:282`），`axis_stroke` 可由用户填任意 ≥0 值：填 0 = 轴线左缘取 0；填半宽 = 几何中心取 0；填全宽 = 右缘取 0。三种档位都在，用户按图选。
  2. 读数端取本列连通域最右墨迹 +1（`digitize.py:308`），与 0 点端同为"右侧外边界"，**ΔP 理论恒为 0**。
  3. 真实现存的 0 点偏差来自轴宽**量测**问题（默认值可能错 4px），不是对齐模型问题 → 见 `STZ-B1`。
- 复活条件：出现两端不同侧闭合的图（如右侧垂直轴 + 左向填充），此时 ΔP 不为零，需重开并考虑按列指定读数端。

## STZ-B5 双线宽分离默认开关（外部文档 §1.2）

- 状态：CLOSED ｜ 2026-11-18
- 原提议：扣除数据轮廓描边宽 ½W_stroke，做 W_axis / W_stroke 双线宽分离。
- 决议：**不采纳为默认开关。**
- 理由：
  1. `plot_type=area` 为纯色填充（rioja/Tilia 产出，主战场），无描边，扣除项恒为 0 → 开关是死配置。
  2. area 填充右边界即数据位置，现有口径已精确。
  3. 真正需要它的是 `plot_type=line`（取最右墨迹 = 中心 + 半线宽），该情形另立 `STZ-B3` 观察。
- 复活条件：见 `STZ-B3`（线宽 >7.5px）。

## STZ-B6 跨列外推满量程

## STZ-C6 过零防抖强制判 0（外部文档 §2.1）

- 状态：CLOSED ｜ 2026-11-18
- 原提议：「当左右扫描跨度均 < ½W_axis 或两者几乎相等且极小，直接判定为 0」。
- 决议：**不采纳。**
- 理由：用不确定度（½W_axis）冒充测量值。跨度 3px 与跨度 0px 物理不同（前者微正/微负，后者无墨），强制归零会造出一个"看起来正常的 0"，违反不变量 1（禁止返回替代数据）。正确形态是标 `ambiguous` 交人判断，或在有夸张层时优先读放大曲线。
- 复活条件：永不。若确需"近零自动归零"，只能作为**用户显式勾选的后处理**，且导出必须带旗标，不得默认开启。

## STZ-C7 hatching 自动识别

- 状态：CLOSED ｜ 2026-11-18
- 原提议：自动识别 hatching（斜线填充）柱/列。
- 决议：**不做。**
- 理由：算法难度高、收益低。用户对该列单独编组 + 人工点拐点更快更准。
- 复活条件：出现 ≥5 张 hatching 图，且用户明确不愿手工点。

## STZ-C8 文字重叠自动处理

- 状态：CLOSED ｜ 2026-11-18
- 原提议：自动剔除压在数据图形上的文字。
- 决议：**不做。**
- 理由：框选 ROI 时避开文字区；无法避开的少量错点手工清理即可，成本低于算法。
