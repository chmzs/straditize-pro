# Caryophyllaceae 覆盖率之争：最终裁定

> 起因：同一列（Caryophyllaceae）在三个不同口径下得出三个数字：
> **1.4%（Lead）｜ 80.9%（QA）｜ 8px/37.5%（fix-engineer）**。
> 这种"同一对象三个答案"本身就是工程事故。本文给出可复述的最终裁定。

---

## 1. 分歧来源：三套不同的"真值"定义

| 提出者 | 真值定义 | 该列分母 | 覆盖率 |
| :--- | :--- | ---: | ---: |
| Lead | `lum <= 150` | 142 px | 1.4% |
| QA | `lum <= 150`（口径同 Lead，但列范围更宽） | 852 px | 80.9% |
| fix-engineer | `lum <= 200`（覆盖灰填充 164–182） | 1027 px | 1.4% |

**三者都不成立**，因为它们的共同前提是"用亮度定义填充"。
而这张图的填充层是**按颜色**区分的，亮度不能唯一确定层级。

## 2. 决定性证据：按颜色簇统计覆盖率

对整张图版，逐颜色簇统计"被软件前景掩膜覆盖的比例"（容差 ≤8）：

| 颜色簇 | 像素数 | 覆盖率 |
| :--- | ---: | ---: |
| 浅粉 `(244,226,226)` | 42,441 | **0.0%** |
| 浅蓝 `(218,226,237)` | 32,675 | **0.0%** |
| 浅灰 `(229,229,229)` | 166,107 | **0.0%** |
| 中灰 `(182,182,182)` | 6,427 | **0.0%** |
| 深红 `(180,60,60)` | 10,338 | **100.0%** |
| 深蓝 `(0,62,137)` | 5,591 | **100.0%** |
| 纯黑 `(0,0,0)` | 141,187 | **100.0%** |

```
Otsu 阈值 = 138.0
```

## 3. 裁定

**软件的默认二值阈值（Otsu 138.0）对这张图的行为是"按明度一刀切"：**

- **明度 ≤ 138 的深色像素**（深红/深蓝/纯黑，157,116 px）→ **100% 纳入** ✅ 正确
- **明度 > 138 的浅色像素**（阴影层，241,223 px）→ **0% 纳入** ✅ 正确（阴影不该进读数）
- **中灰 `(182,182,182)`**（6,427 px）→ **0% 纳入** ❌ **这是唯一真缺陷**

### 3.1 关于阴影层：软件行为是**正确的**

浅粉/浅蓝/浅灰三层（241,223 px）全部被排除，**这是对的** ——
图注明写 "Shadings are five-fold exaggerated"，阴影是视效，不该进读数。
**之前把它当缺陷是误判。**

### 3.2 唯一真缺陷：中灰填充被整体丢弃

`Caryophyllaceae` 列的主填充色是 `(182,182,182)`（明度 182 > 阈值 138），
全图此类像素 **6,427 个，100% 被排除**。

**这才是 D-1 的真实形态，且范围极小**：不是"9/15 列失败"，而是
**"中灰填充（明度 138–200 区间）被丢弃"这一个具体失败模式**。

### 3.3 三个数字为何都不对

- Lead 的 `1.4%`：分母 `lum<=150` 只覆盖该列 142 px，且**大部分是抗锯齿边缘**而非填充主体
- QA 的 `80.9%`：列范围更宽（含更多深色描边），把描边算进了"填充"
- fix-engineer 的 `lum<=200`：分母 1027 px 混入了**邻列渗入的橙色**与阴影边缘

**三者都是"用亮度代理填充"，而填充是按颜色定义的。**

## 4. 教训（本轮最重要的一条）

**度量口径必须绑定"被测对象的定义方式"，而不是它的某个方便代理。**

本次三次翻车的共同结构：

```
被测对象：图版上的"实心填充层"
   ↓ 被代理成
代理指标：亮度 <= 150 / <= 200 / 最深 10%
   ↓ 代理失效原因
该图的层级是**按颜色**定义的，亮度与层级不是一一对应
```

**正确的度量方式**：先用颜色簇分离出层级（本文 §2 的做法），
再统计覆盖率。这样得到的答案是唯一的、可复述的。

**回归钉子**：`tests/unit/test_metric_sanity.py::test_darkest_decile_proxy_is_invalid_on_antialiased_bars`
（QA 建）已经把"最深 10% 不是填充色"固化成永久报警。

```bash
pixi run python - <<'PY'
import numpy as np
from PIL import Image
from straditize_core.session import StraditizeSession

for label, c in {'浅粉':(244,226,226),'浅蓝':(218,226,237),'浅灰':(229,229,229),

    n = int(sel.sum())
    print(f'{label}: {n:>7}px 覆盖 {(sel & m).sum() / max(n,1) * 100:>5.1f}%')
```
