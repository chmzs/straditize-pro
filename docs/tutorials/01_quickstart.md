# 教程 1：三分钟快速上手古生态图谱数字化 (S0 ~ S7 全流程)

本教程指导你如何在 3 分钟内利用 **Straditize Pro v2.0** 的 **7 阶段工作流状态机 (S0 ~ S7)**，将一张地层花粉与古气候图谱扫描件解译为发表级的高保真科研数据矩阵。

---

## 阶段概览：S0 ~ S7 严格工作流

顶部导航条提供 7 个状态胶囊，已完成标记为 `✓`，当前进行中为 `●`，未开始为 `○`：

```
[1.加载] → [2.ROI] → [3.分列] → [4.标尺] → [5.拐点] → [6.校验] → [7.导出]
   ✓          ✓         ✓         ●         ○         ○         ○
```

你可以随时点击已完成的步骤胶囊跳回修改，也可以通过画布下方的**浮动向导岛**点击主按钮顺序推进。

---

## 步骤 1 (S0 -> S1)：载入图谱图片与大图性能保障

1. **载入方式**：
   - 点击顶栏 **[📁 图谱]** 按钮选择本地文件（支持 PNG / JPG / TIFF / WebP）；
   - 或者直接将图片拖拽至中央画布虚线框释放；
   - 快速体验：在顶栏 **“📂 范例...”** 下拉菜单中选择 **`Hoya`** 剖面。
2. **大图与微斜安全防护**：
   - **尺寸预算**：主力覆盖 A4/A3 600 DPI（约 5000×7000 ~ 7000×10000 px）。超过 8000×12000 px 时系统自动弹出安全拦截窗口，可一键选择 50% 降采样加载，内存严格受控在 1 GB 以内；
   - **智能微斜检测 (Radon Deskew)**：载入后系统自动进行氡变换倾角检测。若检测到扫描存在 $\ge 0.3^\circ$ 的微斜，右上角自动滑出提示横幅，点击 **[旋转校正]** 即可 1 秒恢复水平。
3. **完成加载**：图片自适应居中（留白 5%），进入 **S1 阶段**。

---

## 步骤 2 (S1 -> S2)：框选纯数据有效区 (ROI)

1. 工具栏自动切换为 **ROI 模式**（快捷键 `R`）；
2. 画布上呈现 8 个方块控制手柄：
   - 拖拽手柄对齐花粉数据区边界；
   - **地学规范**：**严格将左侧纵坐标轴线、右侧聚类分析树 (CONISS) 与底部刻度排除在框外**；
   - 顶底深度文字标签自动停靠在标尺左外侧，绝不与数据遮挡冲突；
3. 点击底部向导岛 **[👉 确认 ROI 并进入清理 (S2)]**。

---

## 步骤 3 (S2 -> S3)：图像去横线与网格降噪

1. 右侧属性检查器显示当前有效区尺寸；
2. 在 **“图像去横线与网格降噪”** 下拉框选择灵敏度（关 / 弱 / 中 / 强）；
3. **即时透视验核**：按下键盘 **`B`** 键，画布开启双色透视遮罩：
   - 🟢 **青蓝色**：系统保留的花粉墨迹多边形；
   - 🔴 **鲜红色**：形态学算子切除的深度网格横线；
4. 点击底部向导岛 **[👉 确认有效区，开始分列 (S3)]**。

---

## 步骤 4 (S3 -> S4)：核对属种分列与批量导入

1. 系统在纯数据区内精准推导各花粉属种垂直基线（虚线显示）；
2. **侧边栏名单对齐**：
   - 点击左侧侧边栏 **[📋 批量导入]**，直接粘贴来自 Excel 或文献表格的多行属种名称，系统自动纠错并从左到右匹配；
   - 在侧边栏使用 **▲ / ▼** 箭头就地对调相邻属种顺位；
   - 若发现文献中间漏切了一列，点击 **[➕插空列]** 即可在当前位置插入占位列，后续属种名自动向后顺延；
   - 支持顶部的 **`[🔍 快速搜索属种...]`** 即时过滤名单；
3. **画布直观拖拽调宽**：
   - 鼠标悬停在两列分界线上，光标变为 `col-resize` 双向箭头；
   - 直接按住鼠标左键横向拖拽，双向调整左右列宽，松手自动记入撤销栈；
4. 点击底部向导岛 **[👉 确认列对齐，进入标尺标定 (S4)]**。

---

## 步骤 5 (S4 -> S5)：两点式物理标尺标定

1. 选中任意属种列，右侧检查器显示 **两点式 X 轴物理刻度标定**：
   - **端点 1 (原点像素 X)**：对应物理值默认 `0%`；
   - **端点 2 (刻度齿像素 X)**：输入图中标注的物理刻度（如 `20%`、`50%`、`100%`），画布横轴上的橙色刻度齿手柄支持直接拖动微调；
   - 中间呈现**微型渐变物理数轴**，物理跨度一目了然；
2. **对数刻度 (Log) 安全保护**：
   - 炭屑或花粉浓度指标可切换为对数；
   - 若起点值 $\le 0$，Log 选项自动置灰并红字警告拦截，杜绝 $\ln(0)$ 产生异常值；
3. **指定图表形态与放大倍数**：
   - 点击 `[🌊 面积]`、`[📊 柱状]`、`[📈 折线]` 或 `[➕ 符号]`；
   - 若图谱带有局部放大虚线，勾选 `局部放大曲线 (Exaggeration)` 并填入倍数（如 `5×`），导出时系统将自动归一除以 5；
4. 点击底部向导岛 **[👉 确认标尺，开始提取拐点 (S5)]**。

---

## 步骤 6 (S5 -> S6)：多边形轮廓精修与绿色原位重叠比对 (Ghosting)

1. 系统快速提取各列形态多边形与显著控制拐点；
2. **三级物理拐点手柄视觉分级**：
   - 🟡 **实心金黄圆 (r=3.5px)**：物理波峰与波谷极值；
   - ⚪ **空心白圆 (r=2.5px)**：平缓过渡点；
   - 🔵 **实心青圆 (r=3.5px)**：用户手工强控制锚点；
3. **绿色原位半透明重叠层 (Visual Ghosting)**：
   - 画布上浮现一层半透明绿色实心多边形，严密叠合在底图黑白墨迹上方；
   - 肉眼 1 秒看清拟合吻合度；
4. **画布直观编辑**：
   - **左键单击**：在曲线上任意位置点击直接添加强控制点并拉伸轮廓；
   - **左键拖动**：微调锚点位置；
   - **右键单击**：直接删除多余噪点，相邻点自动平滑连接；
   - **撤销/重做**：随时按 `Ctrl+Z` / `Ctrl+Y`；
5. 点击底部向导岛 **[👉 完成精修，进入地学校验 (S6)]**。

---

## 步骤 7 (S6 -> S7)：地学校验与 100% 总和自检门禁

1. **图层独立审查**：
   - 右侧检查器提供 5 大图层独立显隐开关：绿色重叠层、轮廓曲线、物理拐点、深度网格、ROI 框；
2. **全剖面 100% 丰度总和自检门禁**：
   - 点击 **[📊 打开数据表格与 100% 总和自检]**；
   - 弹窗顶部实时计算所有层位的百分比加和（$\sum$ 检验）；
   - 若存在偏离 100% 的异常层位（如漏识属种或穿透峰越界），系统展示警示横幅与偏差范围，直接双击表格单元格可就地修改数值；
3. 点击底部向导岛 **[👉 校验达标，进入导出交付 (S7)]**。

---

## 步骤 8 (S7)：科学数据导出与成果交付

1. 调出左右并列的 **WPD 风格科学数据导出控制台**：
   - **左侧数据区 (占比 75%)**：双向粘性冻结（Double Sticky），表头与 Depth 列固定，纵向横向流畅滚动浏览 70+ 行与 30+ 列；
   - **零 NA 原则**：未观测到属种严格填报为 `0.00`，首列无条件为 `depth`；
2. **多格式导出**：
   - **`[💾 下载 CSV]`**：标准二维花粉百分比数据矩阵；
   - **`[📈 R 脚本]`**：生成开箱即用的 `plot_strat.R`（内置 `rioja::strat.plot` 调用并自动配置各列图表类型与放大倍数）；
   - **`[📦 导出 TAR 包]`**：打包 POSIX UStar 开放项目包，完整封存原图、控制点与标定参数，供日后无损重现。
