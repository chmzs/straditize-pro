教程 2：两点式物理刻度钉标定与对数 (Log) 尺度实战

在传统图表数字化软件中，通常假设每一列从 0 开始、以列宽作为 100% 相对刻度。然而在真实古生态学图谱中，往往存在完全不同的标尺形式：优势属种（100%）、微量属种（20% 或 5%）、跨越数个数量级的对数浓度（Log）或同位素负值区间。为此，Straditize Pro 提出了两点式物理刻度标定系统 (Two-Point Physical Tick Calibration)。

1. 物理标定原理

每一列不再被假定为静态的相对宽度，而是由两个具有明确科学含义的物理锚点定义：

  • 端点 1（基准原点 P₁）：
    • 对应像素：列的基准线像素位置 X₀（Baseline）；
    • 对应物理数值：startValue（通常花粉丰度为 0%，对数浓度为 1 或特定底数，同位素指标为起始数值）。
  • 端点 2（物理刻度齿 P₂）：
    • 对应像素：图谱上印刷刻度齿所在的像素位置 X₁（Tick End）；
    • 对应物理数值：tickValue（用户肉眼在图谱上读出的刻度数字，如 20、50、100 等）。

2. 线性刻度 (Linear Scale) 操作

  1. 选中目标属种列（如 Quercus）；
  2. 在右侧属性面板的 两点刻度标定 区域：
    • 查看 端点 1：默认原点数值为 0；
    • 查看 端点 2：在图谱标题或坐标轴上找到刻度齿标记（例如刻度标注为 20%）；
    • 点击面板上的 [齿:20%] 快捷胶囊（或手动输入 20）；
    • 在画布横轴上，直接用鼠标左右拖动橙色的刻度齿手柄，使其与图谱印刷的 20% 刻度标记完全重合。
  3. 此时该列所有轮廓点自动按以下公式即时换算：
val(x) = startVal + [(x - X₀) / (X₁ - X₀)] × (tickVal - startVal)

3. 对数刻度 (Log Scale) 操作与硬约束保护

对于花粉浓度 (Pollen Concentration) 或微炭屑浓度指标，图谱常采用指数刻度。

切换步骤：

  1. 在右侧属性面板中，找到 刻度尺度 (Scale Type)；
  2. 确保端点 1 的数值严格大于 0（例如输入 1，因为 ln(0) 在实数域无定义）；
  3. 确保端点 2 的刻度值严格大于 0 且不等于起点值（例如输入 1000）；
  4. 点击 对数 (Log) 胶囊切换尺度；
  5. 此时曲线自动依照指数-对数双向映射进行数值变换：
val(x) = exp( ln(startVal) + [(x - X₀) / (X₁ - X₀)] × (ln(tickVal) - ln(startVal)) )

科学安全防护机制：

如果当前端点 1 的数值为 0，Straditize Pro 会立即将 Log 按钮禁用置灰，并在下方以醒目的黄色提示：

⚠️ 数学约束拦截：对数刻度要求起点值 > 0（当前为 0，ln(0) 无定义）。杜绝因误触导致的数据非数 (NaN) 污染或计算死循环。
