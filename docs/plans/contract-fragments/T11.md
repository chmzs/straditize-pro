## 1. OCR 区间归属与三类对账（`straditize_core/ocr/engine.py`）

### 1.1 区间归属规则（取代旧版贪心最近邻）
彻底移除旧版 `_snap_labels_to_columns` 的「贪心最近邻 + 45px 绝对阈值 + `used_col_indices` 独占」逻辑，落地为严格的无顺序敏感区间包含规则（`snap_labels_to_columns`）：
1. **区间包含**：每个标签取其底端锚点 `anchor_x`，落在 `[col.startX, col.endX)` 半开区间内者归属该列；
2. **数量不一致拒绝配对**：若标签数量与列数量不一致（少 1 或多 1），或存在空列/一列多标签，**不做任何强行配对**（`associated_column_id` 保持 `None`），仅输出三类对账清单；
3. **跨界歧义检测**：若标签水平包络 `[min_x, max_x]` 横跨列边界，在归属 `anchor_x` 所在列的同时记入 `ambiguous`；
4. **顺序无关性**：把同一批标签以任意乱序输入，输出的归属字段与三类对账集合逐字段完全一致；
5. **三类对账返回结构**：
   ```python
   {
       "columns_without_label": list[str],  # 缺少标签的列 ID
       "labels_without_column": list[str],  # 落在所有列区间外的标签 ID
       "ambiguous": list[str],              # 横跨多列或同列多标签的歧义标签 ID
       "matched": bool,                     # 仅当 1:1 严格无缺漏时为 True
   }
   ```
