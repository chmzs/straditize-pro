## 1. 采样层位实体与算法接入

### 1.1 采样层位实体规约（`straditize_core/session_parts/samples.py`）
实现 `SampleHorizon` 数据结构：
```python
{
    "row_px": int,                       # 物理像素行号
    "depth": float | None,               # 真实深度/年代数值（未标定时严格为 null，绝不填 0）
    "source": "auto" | "paste" | "manual",# 来源记录（持久化至元数据）
}
```
* **未标定强防线**：未建立 Y 轴标定时，`depth` 严格保持为 `None`，杜绝任何假数据兜底；
* **标定联动计算**：标定完成后，自动按 `slope * row_px + intercept` 精确换算物理深度。

### 1.2 采样共识与外部粘贴接口
* `samples_extract_consensus`：调用多属种拐点聚类算法 `extract_horizon_consensus`，自动反推真实历史取样层位；
* `samples_paste_depths`：支持用户从外部 Excel 复制真实非等距深度层位序列，逆变换映射回像素行；
* `samples_clear` / `samples_set` / `samples_list` 状态管理。

### 1.3 RPC 方法注册（`straditize_core/rpc_methods/samples.py`）
* 登记 `samples.set`, `samples.list`, `samples.clear`, `samples.extractConsensus`, `samples.pasteDepths`。
