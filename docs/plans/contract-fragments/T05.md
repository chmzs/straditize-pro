## 1. 后端候选线分类与排除区实现

### 1.1 候选线检测（`straditize_core/lines.py`）
实现 `detect_line_candidates(ink, roi, columns, ...)`：
* **Kind A (贯穿横向线)**：跨度满足 `line_fraction_h`（默认 75%）且厚度不超过 `line_width_max`；
* **Kind B (贯穿纵向线)**：跨度满足 `line_fraction_v`（默认 30%）且厚度不超过 `line_width_max`（≤2px 强制约束）；
* **Kind C (列内纵向线)**：列内跨度介于 15% 与 30% 之间，归属指定 `column_index`；
* **Kind D**：按 W1 裁决已剔除。

### 1.2 会话清理与掩膜合成（`straditize_core/session_parts/cleanup.py`）
实现 `detect_line_candidates` 与 `apply_line_removal`：
* **排除区绝对优先（契约 v1.3 §6.1）**：排除区（矩形 `rect` 与多边形 `poly`）直接在全局墨迹上挖空；排除区内部的 `restore` 笔迹无条件失效（`effective_restore = restore & ~exclusion`）；
* **局部置脏**：掩膜更新后，仅使所属 ROI 的 `columns_stale = True`，不污染其他无关 ROI；
* **单事实源输出**：合成全局统一的 `grid_line_mask` 与四色 RGBA 叠加层 `overlay_png`（白=保留 / 红=剔除 / 灰=排除区）。

### 1.3 RPC 方法注册（`straditize_core/rpc_methods/cleanup.py`）
* 登记 `algorithm.detectLineCandidates` 与 `algorithm.applyLineRemoval`。
