## 1. 质量诊断实体与算法落地

### 1.1 `QaSummary` 实体规约（`straditize_core/qa.py`）
严格实现《冻结契约 v1.3》§2.7 定义的诊断摘要实体：
```ts
interface QaSummary {
  roi_id: string;
  roi_name: string;
  composition: boolean;
  n_horizons: number;
  n_horizons_with_data: number;
  n_horizons_empty: number;
  empty_horizons: { depth: number | null; reason: string }[];
  sum: { min: number; p50: number; max: number; mean: number };
  tolerance: number;
  violations_over: { depth: number | null; sum: number }[];
  shortfall: { min: number; max: number; mean: number };
  per_column_max: { name: string; peak: number; declared_max: number; over: boolean }[];
}
```

### 1.2 地学门禁校验规则
1. **组分总和门禁**：
   - 当 `composition: true` 时，检查各层位总和是否 $\le 100\% + \text{tolerance}$（默认 $\text{tolerance}=2.0\%$）；
   - 超标层位准确记录于 `violations_over`；
   - 统计正常读数层位的亏缺率 `shortfall`（$\min, \max, \text{mean}$），超标层位亏缺视为 0；
   - 当 `composition: false` 时，如实返回 `sum` 统计，豁免总和门禁报警（`violations_over = []`）。
2. **空层位检查**：
   - 逐层扫描未提取到有效墨迹数据的层位，登记于 `empty_horizons`（标注 `reason: "no ink read"`）；
   - `sum` 总和统计严格包含全零层位，严禁静默剔除。
3. **单列超刻度检查与单一事实源**：
   - 列刻度上限 `declared_max` 严格按契约 v1 §4 由 $\max(x\_ticks[0].value, x\_ticks[1].value)$ 派生，物理杜绝读取旧遗留字段或 UI 默认值；
   - 单列峰值超出 `declared_max` 时标记 `over: true`，刻度调整时动态联动。
4. **空 ROI 防御**：
   - 无列或无采样层位时，返回完整 `QaSummary` 结构且计数为 0，不报错、不编造假数据。
