## 二、 核心任务拆解与技术验收规约

### 任务 1：全地形地学图谱鲁棒性套件 (`tests/test_corpus_robustness.py`)
使用 `@pytest.mark.parametrize` 接入 `tests/corpus/index.json` 中登记的全部 5 张真实复杂地学大图：
1. **01_chinese_scanned_hlines.png**（复印黑边 + 密集横线 + 中文字符，1807x745）
2. **02_muricuo_multicolor_dual_y.jpg**（木里错彩色双 Y 轴 + 顶部分组大括号，2251x1203）
3. **03_lough_inchiquin_vertical_strip.jpg**（竖直超高纵横比全剖面图，1636x2562）
4. **04_elsevier_two_tier_coniss.jpg**（Elsevier 双层多 ROI + CONISS 树，2428x1727）
5. **05_scanned_hatched_lithology.jpg**（斜网格 5x 阴影 + 岩性柱，1476x965）

**断言判据**：
- **Zero Unhandled Exceptions**：整套流水线（载入 $\rightarrow$ 几何建议 $\rightarrow$ 二值化分割 $\rightarrow$ A/B/C 类线检测 $\rightarrow$ 自动分列）在任意分辨率和噪音下 100% 正常返回，0 崩溃、0 未捕获异常；
- **几何与视口有效性**：返回的 `suggested_roi` 严格落在图像物理尺寸 `[0, width] × [0, height]` 内，矩形面积 $>0$；
- **去线安全性保护**：在 `01_chinese_scanned_hlines.png` 密集横向干扰线场景下，算法检测出的横线宽度严格遵守 `width <= 3`，绝不把粗墨迹柱误判为横线。

### 任务 2：跨端全流程用户旅程真机 E2E (`tests/e2e/test_golden_journey.py`)
利用真实 MS Edge 浏览器驱动，针对 `04_elsevier_two_tier_coniss.jpg` 执行跨越全生命周期的 Golden Journey：
1. **真实加载与双 ROI 划分**：Step 1 载入图谱；Step 2 划分 `tree_pollen` 与 `herb_pollen` 两个层级 ROI；
2. **两点 Y 轴真实标定**：Step 3 标定深度 0 到 1300 cm；
3. **去线与排除区建立**：Step 4 运行候选线检测并在 CONISS 树划定矩形排除区；
4. **自动分列与属种确认**：Step 5 提取两层各属种列并断言 ROI 物理隔离；
5. **采样与地学校验**：Step 7 提取拐点与层位；Step 8 执行 `qa.summarize`；
6. **顶栏导出与归档物理核验**：
   - 点击顶栏 `#btn-export-csv` 打开导出对话框；
   - 生成 `.tar` 项目归档包并在测试端真实解包断言：
     - `data/tree_pollen.csv` 存在且首列为 `depth`；
     - `data/herb_pollen.csv` 存在且列名无 ROI 前缀；
     - 根目录 `data.csv` 严格逐字节等价于当前 Primary ROI (`tree_pollen`)；
     - 数据完整无损坏，无非法字符串。
