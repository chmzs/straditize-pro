## 1. 数据模型与实体规约

### 1.1 `DataRoi` (v1.3 §2.1)
已完整落地于 `straditize_core/session_parts/roi.py:RoiMixin`：
```python
{
    "id": str,                          # "roi_1", 单调自增唯一 ID
    "name": str,                        # 唯一命名，校验 ^[\w\u4e00-\u9fa5-]{1,31}$
    "name_source": "default" | "user",  # "default"（如 "pollen"）或 "user"（用户显式命名）
    "composition": bool,                # 组分标记（True 表示各层位总和应 ≤ 100%）
    "visible": bool,                    # 画布叠加图层可见性
    "xlim": [float, float],             # [x_min, x_max]，真实像素横向范围
    "ylim": [float, float],             # [y_min, y_max]，真实像素纵向范围
    "columns_stale": bool,              # per-ROI 脏标记：范围变动置 True，分列后置 False
    "form_defaults": dict | None,       # 仅作为 UI 表单记忆，绝不参与任何计算派生
}
```

### 1.2 `Column` 实体与事实源不变量
* **唯一事实源**：`x_ticks: list[Tick] | None`。
* **物理清除**：彻底消除 `override`、列级 `startValue/tickValue`、`scaleCalib` 以及 `effective_column_settings` 逻辑，杜绝任何隐式继承。

### 1.3 `DiagramData` 扁平容器与指针
* `primaryRoiId`: 主图区指针（.tar 与导出默认取此 ROI）。
* `activeRoiId`: 当前活跃图区。
* `rois`: `DataRoi` 扁平列表。
* `columns`: 全量列扁平列表，通过 `col["roi_id"]` 外键关联。

## 3. 会话 Mixin 架构与初始化规约

`straditize_core/session.py` 通过多重继承组合 8 个独立 Mixin：
```python
class StraditizeSession(
    CoreMixin,
    RoiMixin,
    CleanupMixin,
    XTicksMixin,
    SamplesMixin,
    LayersMixin,
    QaMixin,
    ExportMixin,
):
```
* **MRO 顺序**：`StraditizeSession -> CoreMixin -> RoiMixin -> CleanupMixin -> XTicksMixin -> SamplesMixin -> LayersMixin -> QaMixin -> ExportMixin -> object`。
* **初始化规约**：占位 Mixin 的 `_init_<part>()` 均为空操作（`pass`），严禁在实例化路径抛出 `NotImplementedError`。
