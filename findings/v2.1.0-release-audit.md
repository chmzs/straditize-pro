## 1. 核心问题定位与闭环复盘

在完成主流程重构推进 v2.1.0 发行过程中，针对用户在真实古生态图谱（如带有方波柱状图、断裂夸大曲线、复杂干扰线）的实测反馈，攻坚并彻底解决了以下系统性缺陷：

### 1.1 项目名称全流程自定义与工程前缀防丢失
- **症状**：导入 `pollen_bars_riojaplot_project_20261120_120034.tar` 后，再次导出变成了 `straditize_project_*.tar`，用户自定义前缀丢失，且界面无自定义项目名称入口。
- **根因**：后端在载入工程解压出的 `original.png` 时，文件名落入通用黑名单，被重置为默认的 `"straditize"`；同时顶栏与导出弹窗缺少项目名称的双向绑定机制。
- **修复措施**：
  1. `Toolbar.ts` 与 `ExportModal.ts` 增加项目名称输入框，内存与后端 `project.setName` RPC 实时双向同步；
  2. 导出所有文件（`.tar`, `.csv`, `.xlsx`, `.zip`）动态采用自定义项目名；
  3. 工程载入时解析原 `.tar` 文件名前缀，并在 `straditize.json` 补充持久化 `project_name` 字段。

### 1.2 柱状图（Bar）单峰中心提取与 0 值控制点去噪
- **症状**：柱状图数字化时单根柱条出现多个控制点（上下边缘各取一点），且在基线 0 值处生成大量冗余锚点。
- **根因**：水平方波波峰在列扫描时覆盖了柱条高度区间的所有行，算法此前取了极值跨度的边缘行而非正中物理中心；且未对 0 值处的点进行剔除。
- **修复措施**：
  1. `straditize_core/session_parts/digitize.py` 对柱状图形态提取水平方波物理正中行（`best_rows[len // 2]`）作为单点几何中心；
  2. 基线 0 值处控制点 100% 滤除，杜绝伪锚点。

### 1.3 干扰线清理掩膜无条件重建与防复活
- **症状**：载入已保存工程后，此前用户确认清理的干扰横竖线重新出现。
- **根因**：像素掩膜设计为惰性解耦未序列化入工程包，载入工程后只恢复了矢量对象列表，未触发掩膜重新栅格化。
- **修复措施**：
  1. 工程载入后，按原项目已标记的 `status == "removed"` 干扰线、排除区和笔迹无条件重建派生墨迹掩膜；
  2. 取数层按需懒合成最新掩膜，保证横竖线清理状态 100% 恢复。

### 1.4 组级形态与单位无损继承
- **症状**：在步骤 6 将组形态设为 Bar，工程保存重载后列属性回退为 Area，出图仍画面积图。
- **根因**：载入工程期，列级属性被硬编码默认写入 `"area"` 覆盖了所属组的形态设置。
- **修复措施**：
  1. 保证组形态（`plot_type`）与单位（`unit`）向列无损穿透；
  2. R 出图脚本（`plot_strat.R`）按列动态下发 `plot.poly`, `plot.bar`, `plot.line`, `plot.symb`；
  3. 当组单位为 `%` 时，自动注入 `style$scale.percent <- TRUE`，统一按 0–100% 相同物理比例绘制。

### 1.5 峰谷提取控制点无损合并与步骤 7 单列检查器重开
- **症状**：
  1. 自动提取峰谷控制点时，原有的非 manual 控制点全丢；
  2. 步骤 7 侧栏点选列后，单列删除 `#btn-col-delete` 与重新取数 `#btn-col-digitize` 在界面上找不到。
- **根因**：
  1. `digitize.py:1278` 中 `merged_ctrls = {}` 初始化为空字典，导致未标 manual 的已有控制点丢失；
  2. `SidebarBridge.ts` 在步骤 7 点选列时未同步设置 `selectedEntity`，导致右侧只渲染层位面板未挂载单列 Inspector。
- **修复措施**：
  1. `merged_ctrls` 基于现有控制点字典更新，合并新峰谷并保留历史控制点；
  2. 在 `Inspector.ts` 与 `SidebarBridge.ts` 恢复步骤 7 侧栏点击列同步展示单列 Inspector。
